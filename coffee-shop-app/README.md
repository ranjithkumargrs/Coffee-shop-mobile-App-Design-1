# Coffee Corner

A responsive coffee shop UI built with React, Vite, and Tailwind CSS. The app uses the supplied images in `public/images` and includes onboarding, home, coffee details, favorites, cart, profile, and delivery-tracking screens.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

## Project structure

- `src/components/` contains shared navigation, search, category, coffee-card, and quantity components.
- `src/pages/` contains the app screens.
- `src/data/coffeeData.js` contains the coffee catalog.
- `public/images/` contains the supplied UI and coffee images.

All visual styling is implemented using Tailwind CSS utility classes.
